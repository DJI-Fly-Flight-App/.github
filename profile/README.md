## Overview
DJI Fly for Windows is the app pilots use to control a compatible DJI drone, watch a live camera feed, and plan flights using the built-in DJI Fly map. It's meant to be the single place a pilot checks before, during, and after a flight — from route planning to reviewing the footage once the drone is back on the ground.

## FAQ
**Is DJI Fly the same app as the older DJI GO Fly app?**
No — DJI Fly is DJI's newer app for more recent drone models, while the DJI GO Fly app supports older models; use whichever one matches your drone.

**Is DJI Fly free?**
Yes, DJI Fly is free to download; it's designed to work with DJI drone hardware sold separately.

**Which versions of Windows are supported?**
Recent 64-bit versions of Windows are supported.
